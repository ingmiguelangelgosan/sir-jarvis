# Jarvis

Asistente personal autogestionado, orientado a finanzas conversacionales en Telegram.

**Estado:** Fases 0 y 1A implementadas: diagnóstico local y texto por Telegram
con acceso restringido. IA, persistencia y operaciones financieras siguen pendientes.
Las pruebas de Telegram usan una API simulada; falta la prueba manual con un bot propio.
La licencia definitiva está pendiente de decisión.
